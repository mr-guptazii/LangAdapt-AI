# API

Full interactive docs are auto-generated by FastAPI and available at `/docs` (Swagger) and `/redoc` while the API is running. This file is a map, not a duplicate of that.

Base path: `/api/v1`. Auth: `Authorization: Bearer <jwt>` (obtained from `/auth/login` or `/auth/register`).

| Module | Prefix | Key endpoints |
|---|---|---|
| `auth` | `/auth` | `POST /register`, `POST /login`, `GET /me` |
| `users` | `/users` | `GET /me/profile` |
| `onboarding` | `/onboarding` | `POST /complete` |
| `assessment` | `/assessment` | `POST /start`, `POST /{id}/answer` — adaptive, 8 questions, returns CEFR estimate + breakdown |
| `chat` | `/chat` | `POST /message` — runs the full agent graph |
| `voice` | `/voice` | `POST /transcribe` (multipart), `POST /synthesize` |
| `practice` | `/practice` | `GET /next?skill_code=`, `POST /submit` |
| `vocabulary` | `/vocabulary` | `GET /`, `GET /due`, `POST /review` |
| `progress` | `/progress` | `GET /dashboard`, `GET /mastery`, `GET /accuracy-trend` |
| `mistakes` | `/mistakes` | `GET /` — "Your Learning Memory" |
| `recommendations` | `/recommendations` | `GET /?refresh=` |
| `memory` | `/memory` | `GET /facts`, `GET /decisions` ("Why this lesson?") |
| `sessions` | `/sessions` | `GET /`, `GET /{id}/messages`, `POST /{id}/end` |
| `settings` | `/settings` | `GET /`, `PATCH /`, `POST /export`, `DELETE /account` |
| `analytics` | `/analytics` | `GET /admin/overview` (admin-only, aggregates only) |

## Error shape (every non-2xx response)

```json
{
  "success": false,
  "error": { "code": "VALIDATION_ERROR", "message": "..." },
  "request_id": "..."
}
```

## Example: the core agentic flow

```bash
TOKEN=$(curl -s -X POST localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@lingoadapt.ai","password":"demo1234"}' | jq -r .access_token)

curl -s -X POST localhost:8000/api/v1/chat/message \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"message": "Yesterday I go to the market.", "mode": "conversation", "input_mode": "text"}'
```

Response includes `corrections[]`, `teaching_strategy`, `difficulty_decision`, `recommended_activity`, and `agents_invoked[]` — the full trace of which graph nodes ran for that turn.
